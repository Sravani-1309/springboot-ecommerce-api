Spring Boot Ecommerce REST API

A backend E-commerce REST API built using Spring Boot, Spring Data JPA, and MySQL.
This project provides APIs for user management and product management, forming the foundation of a simple e-commerce system.

Features

User registration and login

Product management APIs

RESTful API design

MySQL database integration

Spring Boot layered architecture

JPA repository abstraction

Tech Stack

Java 17

Spring Boot

Spring Data JPA

MySQL

Maven

REST API

Postman (API testing)
